# Strato Lab

Sito vetrina per un'attività di stampa 3D su richiesta.

## Contenuto
- Servizi: prototipi, piccole serie, ricambi, modellazione 3D, finiture
- Selettore dei materiali (PLA, PETG, ASA, TPU, nylon) con indicatori animati
- Come funziona, lavori tipo, prezzi indicativi e stima rapida del costo
- Domande frequenti e modulo per preparare la richiesta di preventivo

## Tecnologie
HTML, CSS e JavaScript in un unico file, senza librerie esterne.
Font: Roboto Flex e Roboto Mono da Google Fonts.
Stile: Material 3 Expressive.

## Note
Nome, contatti, prezzi e lavori di esempio sono segnaposto
realizzati per un progetto dimostrativo.
